Name:
ketch

Tagline (60 characters max):
Install any CLI tool straight from its GitHub releases

Links:
- Website: https://listepo.github.io/ketch/
- Repo: https://github.com/listepo/ketch
- Release: https://github.com/listepo/ketch/releases/tag/v0.6.0

Description:

ketch installs command-line tools and apps directly from GitHub releases on macOS, Linux and Windows. No formulas, no build step. It picks the right binary, checks the published checksum, keeps every version so you can roll back instantly, and uninstalls cleanly.

Gallery captions:
1. `ketch install listepo/AirTalk`: one command, any repo that ships releases.
2. `ketch why AirTalk`: see exactly which asset was picked and why.
3. `ketch rollback AirTalk`: back to the previous version with no download.
4. `ketch lock` and `ketch sync`: the same toolset on every machine.
5. `ketch self uninstall`: removes everything it ever added.

Maker comment:

Hi Product Hunt! I built ketch because every tool I use already publishes binaries, but installing them was still manual on every machine. v0.6.0 is the first release I'm happy to show widely.
